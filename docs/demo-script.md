# 3분 데모 스크립트 — 운동숙제

> **대상:** 센터장 / 투자자 / 트레이너  
> **목표:** 「15초 숙제 전송 + 기억력 대체(Aha)」를 체감시키기

---

## 사전 준비 (데모 5분 전)

- [ ] `npm run dev` 또는 **Vercel prod URL** 접속
- [ ] Supabase `seed.sql` 적용됨 (김민수 등 5명)
- [ ] **김민수** 회원으로 숙제 1건 이상 `completed` 상태 (컨텍스트 알럿용)  
      → 없으면: 먼저 숙제 보내고 링크에서 완료까지 한 번 진행
- [ ] 휴대폰(또는 시크릿 창) 준비 — 매직 링크용
- [ ] Supabase Table Editor 탭 열어 두기 (선택)

---

## 0:00 — 오프닝 (15초)

> 「운동숙제는 트레이너가 **15초 안에** 회원 숙제를 보내고,  
> 회원은 **앱 설치 없이** 링크만으로 완료하는 도구입니다.  
> 지금부터 실제 플로우를 보여드리겠습니다.」

---

## 0:15 — Aha-moment: 기억력 대체 (45초)

**화면:** 트레이너 워크스페이스 `/`

1. 상단 **「김민수」** 칩 탭
2. 노란 **컨텍스트 알럿** 포인트

> 「회원을 고르는 순간, **지난 숙제에서 가장 힘들었던 운동**이 뜹니다.  
> 트레이너가 기억할 필요 없이, 시스템이 대신 기억합니다.  
> 이게 센터장님이 원하시는 **데이터가 쌓이는 CRM**의 시작입니다.」

---

## 1:00 — 15초 숙제 만들기 (60초)

1. 검색창에 **「스콰트」** 입력 → 운동 탭
2. (선택) **레그 프레스** 추가
3. 큐잉 **「#호흡유지」** 탭
4. 하단 **「저장 및 카카오 전송」** 클릭
5. 공유 시트 또는 **「복사 완료! 카톡에 붙여넣으세요」** 토스트

> 「회원 선택부터 전송까지 **15초**를 목표로 설계했습니다.  
> 키보드 타이핑 없이, 칩과 버튼만으로 끝납니다.」

**링크 URL 복사** → 휴대폰으로 전달 (에어드롭 / 카톡 나에게)

---

## 2:00 — 회원 경험 (60초)

**화면:** `/h/{token}` (휴대폰)

1. **진행률 바** 확인
2. 각 운동 **SET 1, 2, 3…** 탭 (네온 그린 체크)
3. 전 세트 완료 후 **「가장 힘든 운동」** 선택
4. **「완료하기」** → 🎉 완료 화면

> 「회원은 앱도, 로그인도 없습니다.  
> 운동 직후 한 손으로 세트만 누르면 됩니다.  
> 이 데이터가 다음 세션의 **컨텍스트 알럿**이 됩니다.」

---

## 2:45 — 데이터 증명 (30초) (선택)

Supabase → **Table Editor → records**

- 방금 row: `status = completed`
- `micro_hurdle_answer`에 선택한 운동명
- `exercises_json`에 스냅샷

> 「모든 숙제는 JSON 스냅샷으로 저장돼,  
> 나중에 분석·Phase 2 CRM으로 확장할 수 있습니다.」

## Q&A 예상 질문

| 질문 | 답변 |
|------|------|
| 회원 앱은? | 없음. 매직 링크만. |
| 운동 목록 커스텀? | 트레이너가 직접 추가 가능 (기기 localStorage, Phase 2 DB화) |
| 다른 센터 브랜딩? | `--color-primary` CSS 변수로 CI 색만 교체 |
| 15초 실측? | Day 3 KPI 계측 예정 (현재 UX는 15초 목표 설계) |

## 문제 발생 시

| 증상 | 대응 |
|------|------|
| 저장 500 | `.env` / seed 미적용 → 데모 전 김민수로 테스트 전송 1회 |
| 알럿 안 뜸 | 해당 회원 `completed` 레코드 없음 → 사전 완료 1회 |
| 링크 404 | 잘못된 token → 방금 복사한 URL 재사용 |
