# Figma 디자인 논의 프롬프트 — 운동숙제 (Exercise Homework)

아래 프롬프트 전체를 Figma AI / 디자이너 / FigJam 워크샵에 그대로 붙여넣어 사용하세요.

---

## 프롬프트 (복사용)

```
당신은 B2B 피트니스 SaaS 「운동숙제(Exercise Homework)」의 시니어 프로덕트 디자이너입니다.
트레이너가 15초 안에 [회원 선택 → 운동 선택 → 큐잉 → 카카오 링크 전송]을 끝내고,
회원은 앱 설치·로그인 없이 매직 링크로 숙제를 받아 세트별로 완료 체크하는 제품입니다.

### 제품 컨텍스트
- Phase 1 MVP: 센터 트레이너용 생산성 도구 (CRM 아님, 대시보드 최소)
- 핵심 KPI: 트레이너 워크플로우 15초 이내
- 핵심 Aha-moment: 회원 선택 시 「지난 숙제에서 가장 힘들었던 운동」 컨텍스트 알럿
- 회원 UX: 운동 직후/중 — 땀, 피로, 한 손 조작, 키보드 거의 없음

### 디자인 방향 (논의·발전시킬 것)
현재 코드베이스는 「Yeezy Brutalism」을 베이스로 하고 있습니다:
- rounded-none, shadow 없음, animation 최소
- 흑백 강대비 + 포인트 컬러(네온 그린 전송, 노란 컨텍스트 알럿)
- 터치 타겟 h-14~h-16 (56~64px) 이상

하지만 「브루탈리즘」이 UX를 해치지 않도록, 운동숙제에 맞게 **다음을 함께 설계**해 주세요:

1. **정보 위계**: 한 화면에 회원 / 검색 / 운동 리스트 / 선택 패널 / 전송 — 무엇이 1순위 시선인가?
2. **트레이너 vs 회원**: 두 페르소나의 톤 차이 (속도 vs 완료·격려)
3. **한국 피트니스 현장감**: 스콰트, 푸시업 등 한국어 용어, 센터·트레이너·회원 호칭
4. **15초 플로우**: 클릭 수·스크롤·인지 부하 최소화 wireflow
5. **접근성**: 고령 회원, 운동 중 거친 터치, 밝은 체육관 조명

### 산출물 요청
다음 화면에 대한 **모바일 퍼스트 (375px)** 와이어프레임 또는 하이파이 제안을 해 주세요:

**A. 트레이너 워크스페이스 (단일 페이지)**
- 상단: 회원 선택 (가로 스크롤 칩)
- 컨텍스트 알럿: 「○○님이 지난 숙제에서 △△를 가장 힘들어했습니다」
- 운동 검색 + 카테고리 필터 + 리스트
- 선택된 운동: 세트/횟수 stepper, 큐잉 해시태그(프리셋 + 직접 추가)
- 하단 고정: 「저장 및 전송」(CTA)

**B. 회원 매직 링크 페이지**
- 숙제 헤더 + 진행률 바
- 운동별 카드: 이름, 세트×횟수, 큐잉 태그
- **세트별 완료 버튼** (SET 1, SET 2 … 탭)
- 전 세트 완료 후: 마이크로 허들 「가장 힘든 운동?」 + 완료 CTA
- 완료 화면: 격려 메시지

**C. 디자인 시스템 초안**
- Color tokens (primary, alert, success, surface, border)
- Typography scale (한글 font-black/bold 계층)
- Button / Chip / Input / Progress 컴포넌트
- 4px 그리드, border 두께 규칙

### 제약 (MVP 범위)
- 라우팅·모달·드로어 최소 (단일 워크스페이스)
- 회원 앱 설치·로그인 없음
- 복잡한 차트·Admin 대시보드 Phase 2 이후

### 논의 질문 (우리 팀과 함께 답해 주세요)
1. Brutalism을 유지할 때 「세련됨」을 어떻게 더할까? (여백, 타이포, 컬러 비율)
2. 컨텍스트 알럿은 얼마나 「 때리는」 정도가 적당한가? (데모용 vs 일상용)
3. 회원 세트 버튼: 2열 그리드 vs 1열 리스트 — 현장에서 더 빠른 쪽은?
4. 트레이너 브랜드 컬러를 센터별 화이트라벨로 바꿀 여지를 어디에 둘까?
5. 카카오톡 링크 미리보기(OG)에 보일 썸네일·카피는?

### 참고 무드 (키워드)
「현장 도구」「15초」「손가락 하나」「숙제」「트레이너의 기억력 대체」
Yeezy / Brutalism / Swiss grid — 단, **한국 PT 센터**에 어색하지 않게.

먼저 **디자인 원칙 3~5개**와 **A·B 화면 와이어**를 제안하고,
그다음 컴포넌트 토큰과 함께 Figma frame 구조(페이지/섹션 naming)를 제안해 주세요.
```

## 사용 팁

| 상황 | 방법 |
|------|------|
| Figma Make / AI | 위 프롬프트 + 현재 스크린샷 1~2장 첨부 |
| 디자이너 1:1 | 「논의 질문」5개만 골라 미팅 아젠다로 사용 |
| FigJam | A·B user flow를 sticky로 붙이고 Brutalism 레퍼런스 보드 병행 |

## 현재 구현 스냅샷 (디자이너 공유용)

- 트레이너: `http://localhost:3000`
- 회원: `http://localhost:3000/h/{magic_token}`
- 스택: Next.js, Tailwind, 모바일 퍼스트, Zustand
